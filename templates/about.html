About College Predictor

College Predictor is a machine-learning-based college recommendation system designed to help students explore colleges based on entrance exam, rank and branch preferences.

🤖

Machine Learning

The system uses a Random Forest based machine learning model as part of the college prediction process.

🎓

College Database

The project combines KCET and EAMCET college records so students can browse and compare available information.

🔎

Smart Search

Students can search and filter colleges based on exam, branch, state, rating and management fees.

⚙️ Technologies Used

🐍 Python
🌐 Flask
🐼 Pandas
🤖 Scikit-learn
💾 SQLite
🎨 HTML & CSS & JavaScript
